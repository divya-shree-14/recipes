🍽️ Three Recipes
Description
Three Recipes is a simple website created using HTML. It showcases three delicious recipes with their descriptions, ingredients, and step-by-step preparation methods.
Recipes Included

Vegetable Fried Rice
Chocolate Milkshake
Masala Dosa

Features

Simple and easy-to-understand layout
Separate HTML pages for each recipe
Ingredients list for every recipe
Step-by-step preparation instructions

Technologies Used

HTML5

Project Structure
recipes/
├── README.md
├── index.html
├── chocolatemilkshake.html
├── masaladosa.html
└── vegfriedrice.html

How to View

Open index.html in a web browser.
Select a recipe to view its ingredients and preparation steps.
