# 🍽️ Recipes

Discover simple recipes. Explore ingredients. Start cooking!
A beginner-friendly recipe webpage built using HTML, featuring three delicious dishes with their descriptions, ingredients, and step-by-step preparation instructions.

## 🍴 Recipes Featured
🥞 1. Masala Dosa<br>
A classic South Indian dish featuring crispy dosa filled with spiced potato masala.<br>
🧋 2. Chocolate Milkshake<br>
A soft and chocolatey dessert that's quick and easy to prepare.<br>
🍚 3. Vegetable Fried Rice<br>
A flavourful rice dish prepared with fresh vegetables and simple seasonings.<br>



## ✨ Features

- Three delicious recipes in one webpage<br>
- Recipe descriptions<br>
- Ingredients lists<br>
- Step-by-step preparation instructions<br>
- Simple and easy-to-navigate layout<br>

## 🛠️ Technology Used

- HTML5<br>

## 🚀 Getting Started

- Clone or download this repository.<br>
- Open the project folder.<br>
- Open index.html in your web browser.<br>

## 🎯 Learning Objectives

- Practice HTML fundamentals<br>
- Organize webpage content using headings and lists<br>
- Adding images using the <img> tag<br>
- Using image URLs as sources<br>
- Present information in a clear, structured format<br>
